# 本目录的规矩

你在 `workspace/` 里工作。那是唯一允许改动的目录。

1. **不许删除任何文件。** 只能移动。不确定的，别动。
2. **移动前先看目标位置有没有同名文件。** 有就停下来，在报告里说出来，等人决定。**永远不要覆盖。** 用 `mv -n`，不要用裸 `mv`。
3. **动手前先数一遍文件总数，动完再数一遍。** 两个数字必须对上，对不上就停下来报告。
4. **后缀不等于内容。** 归类前先看一眼文件本身是不是它后缀说的那种格式。看不准的别硬猜，放进 `待确认/` 并说明理由。
5. **最后用一句话报告：** 移了多少、现在多少、有哪几个你没动、为什么。

直接用 shell 命令处理，不要另写脚本。
